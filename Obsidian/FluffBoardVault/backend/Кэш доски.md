# Кэш доски

Parent: [[Index]]

## Назначение

`backend/BoardCache.cs` хранит в памяти процесса короткие снимки ответов GitHub, чтобы открытие доски не ожидало повторного чтения одних и тех же данных. Кэшируется результат, уже преобразованный [[backend/GitHubClient]]: issues вместе с прямыми ссылками аватаров исполнителей, комментарии задачи, labels, статусы и список назначаемых пользователей.

## Правила

- Время жизни каждого значения — одна минута.
- После `POST` или `PUT` задачи кэш issues немедленно сбрасывается.
- Создание метки, статуса или изменение задачи сбрасывает кэш labels и статусов, поскольку GitHub может создать служебный label при записи.
- Кэш не сохраняется на диск и очищается при перезапуске backend; GitHub остаётся единственным источником истины.

## Методы

| Метод | Описание |
|---|---|
| `GetIssuesAsync(...)` / `GetCommentsAsync(...)` | Возвращают кэшированный список задач или комментариев; ключ комментариев включает номер задачи. |
| `GetLabelsAsync(...)` / `GetStatusesAsync(...)` / `GetAssigneesAsync(...)` | Возвращают кэшированные данные справочников, включая прямые URL аватаров назначаемых пользователей. |
| `InvalidateIssues()` | Сбрасывает issues после создания или изменения задачи. |
| `InvalidateLabelsAndStatuses()` | Сбрасывает labels и статусы после изменения задачи, метки или статуса. |
