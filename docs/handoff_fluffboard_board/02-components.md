# 02 — Компоненты и точный копирайт

Порядок сверху вниз. Все размеры — из макета; строки интерфейса приведены дословно.

## 1. Шапка (`header`)

Flex, `space-between`, `gap:20px`, `flex-wrap`, снизу граница `--border`, `padding-bottom:20px`.

Слева:
- логотип-квадрат 44×44, radius 13px, фон `--accent`, буква «F» 800/20px `--accent-ink`, `--shadow`;
- заголовок **«Доска задач»** + моно-бейдж **«GITHUB ISSUES»** (фон `--chip`, граница, radius 6px, padding 4px 8px);
- подпись: **«Все изменения задач сразу записываются в GitHub»**.

Справа:
- primary-кнопка **«+ Новая задача»** (фон `--accent`, 700/14px, padding 10px 18px, radius `--rad`) → открывает модалку создания;
- разделитель (левая граница, `padding-left:12px`), затем аватар текущего пользователя (32px, `#2563eb`), логин **«liis17»** (600/14px) и кнопка **«Выйти»** (outline, 600/13px, padding 7px 13px).

## 2. Плитки-метрики (5 шт.)

Grid `repeat(auto-fit, minmax(148px, 1fr))`, `gap:12px`, `margin-top:22px`.
Плитка: `--card-bg`, граница, radius `--colrad`, padding 15px 16px, `--shadow`.
Внутри: строка «подпись + цветная точка 9px», ниже число 800/28px и суффикс 600/12px.

| Подпись | Значение | Суффикс | Цвет точки / суффикса |
|---|---|---|---|
| Всего задач | всего задач | issues | `#94a3b8` / `--muted` |
| Готово | кол-во `done` | `<N>%` | `#16a34a` |
| В работе | кол-во `progress` | активны | `#2563eb` |
| К выполнению | кол-во `todo` | в очереди | `#f59e0b` |
| Приоритетные | `urgent`+`high`, кроме `done` | «требуют внимания» / «нет» если 0 | `#dc2626`; при 0 суффикс `--muted` |

## 3. Тулбар

Flex, `gap:12px`, `flex-wrap`, `margin-top:22px`.

- **Поиск**: контейнер `--card-bg` + граница, radius `--rad`, padding 8px 13px, `flex:1`, `min-width:230px`, `max-width:360px`; инлайн-svg лупа 16px (stroke `--muted`, width 2); инпут без рамки, 500/14px, плейсхолдер **«Поиск задач…»**. Фильтрует по заголовку и по номеру задачи.
- **Переключатель режимов**: контейнер `--chip` + граница, radius `--rad`, padding 3px, `gap:2px`; кнопки **«Доска» / «Список» / «Таблица»**, 600/13px, padding 7px 14px, radius `calc(var(--rad) - 3px)`; активная — фон `--accent`, текст `--accent-ink`; неактивная — прозрачная, текст `--muted`.
- **Группировка**: label `--card-bg` + граница, radius `--rad`, padding 7px 11px; текст **«Группировка»** 500/13px `--muted` + нативный `<select>` (600/13px, без рамки) со значениями **Статус / Исполнитель / Лейбл**.

## 4. Фильтр по лейблам

`margin-top:14px`, flex-wrap, `gap:8px`. Подпись **«Фильтр:»** 600/12px `--muted`, затем
чип на каждый лейбл: 600/12px, padding 5px 11px, radius 20px. Выключен — прозрачный фон,
граница `--border`, текст `--muted`; включён — фон и текст из палитры лейбла.
Логика — **AND** (задача должна иметь все выбранные лейблы). Если выбран хотя бы один,
справа появляется текстовая кнопка **«сбросить»** (600/12px, подчёркнутая).

## 5. Блок прогресса

`--card-bg`, граница, radius `--colrad`, padding 18px 20px, `--shadow`, `margin-top:16px`.

- слева: подпись **«Общий прогресс»** 600/12px `--muted`, затем **«<N>%»** 800/34px и
  **«готово из <M> задач»** 600/13px `--muted`. Процент = done / всего, округление `Math.round`.
- справа: легенда по статусам — точка 10px (radius 3px) + число 700/14px + название 500/12px, `gap:18px`.
- ниже: полоса высотой 12px, radius 20px, фон `--track`, `gap:3px`; на каждый статус
  сегмент `width: <доля>%`, цвет точки статуса, radius 6px, `title` = «<Статус>: <N>».

## 6. Режим «Доска»

Горизонтальный flex, `gap:16px`, `overflow-x:auto`, `align-items:flex-start`, `padding-bottom:14px`.

**Колонка**: `width:--colw` (332px), `flex:none`, фон `--colbg`, граница `--colborder`
(в состоянии drag-over → `--accent`), radius `--colrad`, padding `--colpad`.
Шапка колонки: точка 9px (radius 3px) + название 700/15px + счётчик-пилюля справа.
Список карточек: flex-column, `gap:--cardgap`, `margin-top:12px`.
Пустая колонка: пунктирный блок с текстом **«Перетащите сюда»** (500/13px `--muted`,
padding 16px 6px, dashed `--border`, radius `--rad`).
В конце ряда, **только при группировке по статусу**, кнопка **«+ Колонка»**:
150×min 120px, dashed граница, 600/14px `--muted`, hover → `--accent`.

**Карточка задачи** (`draggable`), flex-column, `gap:9px`, `--card-bg`, граница
`--cardborder`, **левая кромка 3px цвета приоритета**, radius `--rad`, padding `--cardpad`,
`cursor:grab`, `--shadow`, hover: граница `--accent` + `translateY(-1px)` (140ms).
Содержимое:
1. строка: пилюля приоритета (иконка + подпись) и справа `#<номер>` 600/12px моно `--muted`;
2. заголовок 700/14px/1.32;
3. лейбл-чипы (wrap, `gap:6px`);
4. подвал: стопка аватаров + перечисление имён через запятую или **«Не назначен»** (500/12px `--muted`), справа ссылка **«GitHub ↗»** (600/12px, `opacity:.6`).

Клик по карточке (кроме ссылки GitHub — там `stopPropagation`) открывает модалку задачи.

## 7. Режим «Список»

`margin-top:22px`, вертикальный стек групп, `gap:22px`. У группы — та же шапка
(точка + название 700/14px + счётчик моно 12px), затем «таблица» строк: контейнер с фоном
`--border` и `gap:1px` (это и рисует разделители), граница, radius `--rad`, `overflow:hidden`.

Строка: flex, `align-items:center`, `gap:12px`, padding 11px 14px, фон `--card-bg`,
hover `--chip`, курсор pointer. Колонки по порядку: иконка приоритета (мин. 16px,
цвет приоритета) · `#<номер>` (моно 12px, width 44px) · заголовок (600/14px, `flex:1`,
`min-width:120px`) · лейбл-чипы · аватары (блок width 110px, выравнивание вправо).

## 8. Режим «Таблица»

Один блок: граница, radius `--rad`, `overflow:hidden`, `margin-top:22px`. Группировка
не применяется — плоский список отфильтрованных задач.

Сетка (шапка и строки одинаковая): `60px 1fr 150px 200px 130px 110px`.
Шапка: фон `--chip`, нижняя граница, padding 11px 16px, моно-капс 600/11px `--muted`,
заголовки: **# · ЗАДАЧА · СТАТУС · ЛЕЙБЛЫ · ИСПОЛНИТЕЛЬ · ПРИОРИТЕТ**.
Строка: padding 12px 16px, нижняя граница, фон `--card-bg`, hover `--chip`, курсор pointer.
Статус выводится названием в цвете точки статуса; приоритет — пилюлей без границы.

## 9. Модалка «Новая задача»

Скрим: `position:fixed; inset:0`, фон `--scrim`, `backdrop-filter: blur(3px)`,
центрирование, `padding:24px`, `z-index:50`, анимация `fbfade`. Клик по скриму закрывает.

Панель: `max-width:540px`, `max-height:90vh`, `overflow-y:auto`, `--card-bg`, граница,
radius 18px, тень модалки, анимация `fbpop`.

- **Шапка** (padding 22px 24px, нижняя граница): моно-капс **«НОВАЯ ЗАДАЧА»**, заголовок
  **«Создать issue»** 800/21px; справа кнопка **×** 34×34, фон `--chip`, radius 10px.
- **Тело** (padding 22px 24px, `gap:20px`):
  - **Название** — инпут, плейсхолдер **«Что нужно сделать?»**, 600/15px, padding 12px 14px, radius 11px, фон `--field`; focus → граница `--accent`.
  - **Описание** — textarea 3 строки, плейсхолдер **«Контекст, шаги воспроизведения, ссылки…»**, 500/14px/1.5, `resize:vertical`.
  - **Статус** — пилюли по всем статусам: точка 7px + название, 600/13px, padding 8px 13px, radius 9px; выбранная — фон `--accent`, текст `--accent-ink`.
  - **Приоритет** — 5 пилюль (иконка + подпись); выбранная — фон = цвет приоритета, текст белый.
  - **Лейблы** — чипы-переключатели, radius 20px, 600/12.5px; выбранный — цвета лейбла.
  - **Исполнители** — чипы с мини-аватаром 18px, radius 20px, padding 6px 13px 6px 7px; выбранный — фон `--accent`.
- **Футер** (sticky bottom, верхняя граница, padding 18px 24px, выравнивание вправо):
  **«Отмена»** (outline) и **«Создать задачу»** (primary). Пустое название — сабмит игнорируется.

Дефолт черновика: статус `todo`, приоритет `medium`, лейблы и исполнители пустые.

## 10. Модалка задачи (просмотр/редактирование)

Как выше, но `max-width:620px`.

- **Шапка**: `#<номер>` (600/13px моно `--muted`) + ссылка **«GitHub ↗»**; справа **×**.
- **Тело**: заголовок — inline-редактируемый инпут 800/22px/1.3 с прозрачной рамкой
  (focus → граница `--border` + фон `--field`; отрицательные margin −6px/−8px, чтобы
  текст не «прыгал»), плейсхолдер **«Название задачи»**; далее **Описание**
  (textarea 4 строки, плейсхолдер **«Добавьте описание…»**), **Статус**, **Приоритет**,
  **Лейблы**, **Исполнители** — те же контролы, что в создании.
- **Футер**: слева **«Удалить»** (граница `--danger-bd`, текст `--danger`, hover фон
  `--danger-bg`), справа **«Закрыть»** (outline) и **«Сохранить»** (primary).
  Пустое название — сохранение игнорируется.

Правки применяются к локальной копии задачи и коммитятся только по «Сохранить».
