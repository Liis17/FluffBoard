# 01 — Дизайн-токены

Все значения взяты из макета дословно. В прототипе они объявлены как CSS-переменные на
корневом элементе (объект `VARS` в логике) — в реальном проекте это должен быть
theme-объект / CSS-переменные / tailwind-конфиг, но **имена и значения сохранить**.

## Базовая палитра (светлая тема)

| Токен | Значение | Применение |
|---|---|---|
| `--bg` | `#f5f6f8` | фон страницы |
| `--text` | `#16181d` | основной текст |
| `--muted` | `#6b7280` | подписи, счётчики, плейсхолдеры |
| `--card-bg` | `#ffffff` | карточки, модалки, строки списка/таблицы |
| `--chip` | `#eef0f3` | чипы, шапка таблицы, hover строк, кнопка × |
| `--field` | `#f7f8fa` | фон полей ввода и невыбранных пилюль |
| `--border` | `#e4e6ea` | все границы и разделители |
| `--track` | `#e9ebef` | подложка прогресс-полосы |
| `--accent` | `#16181d` | primary-кнопка, активный таб, выбранная пилюля |
| `--accent-ink` | `#ffffff` | текст на акценте |
| `--scrim` | `rgba(22,24,29,.4)` | затемнение под модалкой (+ `backdrop-filter: blur(3px)`) |
| `--danger` | `#dc2626` | «Удалить» |
| `--danger-bd` | `#f0c4c4` | граница «Удалить» |
| `--danger-bg` | `#fef2f2` | hover «Удалить» |

Акцент здесь намеренно почти-чёрный: цветом кодируются приоритет, статус и лейблы,
а не элементы управления. Не заменять акцент на брендовый синий без правки лейблов.

| `--cardpad` | `14px` | внутренний отступ карточки |

| радиус полей в модалке | `11px` | инпуты, textarea, пилюли |

Прочие отступы (не токенизированы, но обязательны): контейнер `max-width:1500px`,
`padding:26px 30px 60px`; вертикальные интервалы между секциями `22px`; шапка —
`padding-bottom:20px` + нижняя граница; сетка метрик `repeat(auto-fit,minmax(148px,1fr))`,
`gap:12px`; зазор колонок доски `16px`.

## Приоритеты (5 уровней)

Порядок в UI строго: `urgent → high → medium → low → none`.

| Ключ | Иконка | Подпись | Цвет | Фон пилюли |
|---|---|---|---|---|
| `urgent` | 🔥 | Срочно | `#dc2626` | `#fef2f2` |
| `high` | ↑ | Высокий | `#ea580c` | `#fff7ed` |
| `medium` | = | Средний | `#ca8a04` | `#fefce8` |
| `low` | ↓ | Низкий | `#64748b` | `#f1f5f9` |
| `none` | · | Без | `#94a3b8` | `#f8fafc` |

Граница пилюли — цвет приоритета с альфой `2e` (18%). Левая кромка карточки —
`border-left: 3px solid <цвет приоритета>`.

## Анимации

| Что | Значение |
|---|---|
| появление модалки | `fbpop` 220ms `cubic-bezier(.2,.8,.3,1)`: opacity 0→1, translateY 10px→0, scale .985→1 |
| появление скрима | `fbfade` 160ms ease |
| hover карточки | 140ms ease: `border-color → --accent`, `translateY(-1px)` |
| перетаскивание | у источника `opacity:.4`; у колонки-цели граница → `--accent`, переход 150ms |
| прогресс-сегменты | `width` 300ms |
| hover primary-кнопки | `filter: brightness(1.12)` |
| hover строки списка/таблицы | фон → `--chip` |
| focus поля | `border-color → --accent` |

Скроллбар: 10px, thumb `rgba(120,140,170,.28)`, radius 20px, трек прозрачный.
