# FluffBoard 🐾

> Удобная Kanban-доска для задач одной GitHub-репозитории.

FluffBoard превращает GitHub Issues в рабочее пространство команды: задачи остаются в GitHub, а доска даёт понятный визуальный интерфейс для планирования, просмотра и обновления работы. Изменения, сделанные в FluffBoard, сразу сохраняются в выбранной репозитории.

## Что умеет

| Возможность | Как это работает |
| --- | --- |
| GitHub Issues как источник правды | Загружает задачи, метки, исполнителей и комментарии из одной настроенной репозитории. |
| Три представления | Переключайтесь между доской, компактным списком и таблицей. |
| Гибкая группировка | Раскладывайте задачи по статусу, платформе, исполнителю или метке. |
| Быстрая работа с задачами | Создавайте и редактируйте задачи, меняйте статусы, приоритеты, платформы, метки и исполнителей. |
| Перетаскивание карточек | Переносите задачи между колонками; изменения сразу отправляются в GitHub, а интерфейс обновляется оптимистично. |
| Поиск и фильтры | Ищите по названию или номеру задачи, комбинируйте фильтры по меткам. Состояние вида сохраняется в URL — ссылкой можно поделиться. |
| Контекст задачи | Просматривайте Markdown-описание, изображения и комментарии GitHub; новые изображения можно прикрепить из формы задачи. |
| Прогресс команды | Видны ключевые метрики и прогресс по всей доске, независимо от активных фильтров. |
| Защищённый доступ | Локальные пользователи входят по cookie-сессии; пароли хранятся в SQLite только в виде PBKDF2-хешей. |

## Как устроено

```text
React 19 + Vite
       │ /api
       ▼
ASP.NET Core (.NET 10)
       ├── GitHub REST API — задачи, метки, исполнители, комментарии
       └── SQLite — пользователи FluffBoard и хеши паролей
```

В production Vite-клиент собирается в `wwwroot` backend-приложения. Это один origin: браузер работает с API и статикой по одному адресу, а для раздачи фронтенда не нужен отдельный сервер.

## Быстрый старт

### 1. Подготовьте окружение

Понадобятся .NET 10 SDK и актуальная LTS-версия Node.js с npm. Скопируйте пример конфигурации:

```bash
cp .env.example .env
```

В `.env` заполните минимум следующие значения:

| Переменная | Назначение |
| --- | --- |
| `GitHub__Token` | Fine-grained GitHub token с правом **Issues: Read and write** на нужную репозиторию. |
| `Board__Repository__Owner` | Владелец репозитории. |
| `Board__Repository__Name` | Название репозитории. |
| `Board__Users__0__Username` / `Password` | Учётные данные первого пользователя доски. |

При необходимости для пользователя можно также указать `Board__Users__0__GitHubLogin` и `Board__Users__0__TelegramId`. Добавляйте следующих пользователей с индексами `1`, `2` и так далее.

> `.env` и локальная папка `data/` не попадают в Git. Пользователи синхронизируются с SQLite при запуске приложения.

### 2. Установите зависимости и запустите приложение

В двух терминалах из корня проекта:

```bash
npm ci --prefix frontend
dotnet run --project backend
```

```bash
npm run dev --prefix frontend
```

Откройте [http://localhost:5173](http://localhost:5173). В development-режиме Vite проксирует запросы `/api` на backend по адресу `http://localhost:5279`.

### Запуск на macOS

Чтобы backend загрузил корневой `.env` с приоритетом над переменными процесса, запустите его с флагом `--mac`:

```bash
dotnet run --project backend -- --mac
```

Недостающие в `.env` значения по-прежнему могут прийти из переменных окружения процесса.

## Развёртывание

Приложение публикуется одним Docker-образом. На сервере контейнер доступен только через loopback, а внешний HTTPS завершается отдельным nginx.

```bash
cd docker/fluffboard
cp sample.env .env
# заполните .env: порт, GitHub token, репозиторий и пользователей
docker login docker.barkfluff.com:5000
docker compose up -d
```

Контейнер публикует `127.0.0.1:${FLUFFBOARD_PORT}` и ожидает nginx на хосте. Конфигурация nginx лежит в [`docker/nginx/fluffboard.conf`](docker/nginx/fluffboard.conf), а подробный сценарий — в [документации по развёртыванию](Obsidian/FluffBoardVault/Развёртывание.md).

При push в `main` GitHub Actions собирает и публикует Docker-образ.
